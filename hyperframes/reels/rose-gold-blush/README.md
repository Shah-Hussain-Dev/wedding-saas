# Rose Gold Blush — HyperFrames reel (9:16)

Mirrors slide timings in [`config/template-reels.ts`](../../../config/template-reels.ts).

## Requirements

- Node.js 22+
- FFmpeg

## Commands

```bash
cd hyperframes/reels/rose-gold-blush
npm run dev      # preview in browser
npm run check    # lint + validate
npm run render   # default output under renders/
```

From repo root:

```bash
npm run reels:render:rose-gold-blush
```

Output: `public/reels/rose-gold-blush.mp4` — enables **Download** on `/reels/rose-gold-blush`.
